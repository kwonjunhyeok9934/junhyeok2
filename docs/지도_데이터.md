# 여행 탭 지도 데이터

여행 탭에서 색칠하는 지도는 `js/koreamap.js` 한 파일이다. **자동 생성 파일이라 손으로 고치지 않는다.**

```js
export const VIEWBOX = '0 0 1600 2645';
export const REGIONS = [{ c: '39010', n: '제주시', s: '제주', d: 'M…Z' }, …];  // 229개
export const SIDO_ORDER = ['서울', '부산', …];
```

- `c` — 시군구 코드. `visited_regions.code` 에 그대로 저장하는 키라서 **바뀌면 칠한 게 어긋난다.**
- `n` 이름 · `s` 시도 · `d` SVG path (viewBox 좌표)

## 다시 만들기

```bash
pip install shapely topojson
python3 tools/build_korea_map.py          # 기본값
python3 tools/build_korea_map.py 0.006 6  # 더 거칠게 (파일이 작아진다)
```

원본(통계청 2018 시군구 경계, 18MB)은 스크립트가 `tools/` 에 내려받아 두고 쓴다. 이 원본은 커밋하지 않는다(`.gitignore`).

## 어떻게 만들어진 지도인가

- 출처: [southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps) 의 `kostat/2018` — 통계청 자료, 자유 이용
- 250개 시군구 중 **일반시의 구는 시 하나로 합쳤다** (수원시장안구·권선구·팔달구·영통구 → 수원시). 광역시 자치구는 그대로 둬서 229개가 됐다.
- 경계선을 **공유한 채** 단순화했다(topojson). 지역별로 따로 줄이면 사이에 흰 틈이 생긴다.
- 아주 작은 섬은 뺐고, **울릉군은 동해 쪽으로 당겨** 그렸다. 원래 자리(동경 131°)대로 그리면 본토가 그만큼 작아진다.
  같은 이유로 백령도·가거도처럼 멀리 떨어진 섬은 그리지 않는다 — 옹진군·신안군은 가까운 섬으로 누를 수 있다.
- 좌표는 등장방형 투영(위도 36.2° 보정) 후 정수로 반올림했다.

## 코드가 바뀌면

지도를 새 연도 자료로 다시 만들면 코드가 달라질 수 있다. 그때는 `visited_regions` 의 `code` 를 함께 옮겨야 한다.
`visited_regions.name` 에 칠할 당시의 이름을 같이 저장해 두므로 이름으로 다시 이어 붙일 수 있다.
